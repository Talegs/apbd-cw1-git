# apbd-cw1-git

Ćwiczenia 1 z APBD: Git i Github. Repozytorium dokumentuje utworzenie repozytorium, zapisywanie zmian w commitach, pracę na gałęziach oraz scalanie.

## Opis programu

GitPractice jest niewielką aplikacją konsolową w C#. Dla zdefiniowanej tablicy liczb program wyświetla:
- powitanie,
- sumę elementów,
- średnią arytmetyczną,
- liczbę elementów,
- wartość maksymalną.

## Uruchomienie

```bash
git clone https://github.com/Talegs/apbd-cw1-git.git
cd apbd-cw1-git
dotnet build
dotnet run
```
